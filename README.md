# Tkinter Practice 🐍

This repository contains my personal Python Tkinter practice programs and notes. I created it while learning how to build GUI (Graphical User Interface) applications using Python.

## Topics Covered

- Creating GUI windows
- Labels, Buttons and Entry widgets
- `pack()`, `place()` and `grid()` geometry managers
- Functions and event handling
- Lambda functions
- Getting and displaying user input
- Building a simple calculator

## Calculator Project

A basic calculator built using Python and Tkinter.

**Features:**
- Addition
- Subtraction
- Multiplication
- Division
- Clear button

## Requirements

- Python 3.x
- Tkinter
